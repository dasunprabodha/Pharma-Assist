# Test log

Manual and automated test cases for the Prescription Reader. TC1–TC3 run on 05/10/2026 through the real UI and Amazon Nova 2 Lite
(`us.amazon.nova-2-lite-v1:0`, us-east-1); TC3 used a second backend instance with an invalid model ID.

**Samples:** images from a public dataset of Bangladeshi handwritten prescriptions (patient details absent or pixelated; checked
before upload). They are not Sri Lankan, and their directions are in Bengali, so they are harder than the target use case.
None of the drugs is in the simulated stock list, so every item is correctly flagged "Not found in stock list".
The ground truth is the student's own reading, and the "pharmacist" corrections were made by the student.
