Privacy & safety

  • Photos are resized and stripped of all metadata before they are sent, and are never stored.
  • The model is told to ignore patient name, address, age and doctor details.
  • Only drug items, token counts and timings are logged (logs/, git-ignored).
  • No API keys in the code or repository – the AWS credential chain is used.
  • Decision support only – the pharmacist confirms every item.

Cost estimate

Dashboard costs use PRICE_INPUT_PER_1M / PRICE_OUTPUT_PER_1M (default $0.33 / $2.75, Nova 2 Lite US inference profile). Confirm against the AWS pricing page and your bill.
